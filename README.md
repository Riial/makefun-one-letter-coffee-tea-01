The program writes exactly one letter — **A for coffee** — to `/output/entry.txt`. One byte, no newline, no punctuation.

Why A: the house judge weighs vividness first. Tested against the judge's own brief, A reads as the bolder stance — the first letter behind the bolder brew — while tea's B lands quieter.
